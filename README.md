# 🎮 Tic Tac Toe

A modern, responsive implementation of the classic Tic Tac Toe game built with HTML, CSS, and JavaScript.
It supports both **two-player mode** and **play against computer (AI)** with a clean, minimal game interface.

---

## 🧩 About the Project

This project reimagines Tic Tac Toe with a focus on **smooth gameplay, clean UI design, and structured game logic**.

It is designed to feel like a real casual game experience rather than a simple demo—emphasizing usability, clarity, and responsive interaction.

---

## 🎯 Game Modes

### 👥 Player vs Player

* Classic 2-player mode (X vs O)
* Turn-based gameplay
* Instant win/draw detection

### 🤖 Player vs Computer

* Play against an AI opponent
* Computer makes automatic moves
* Strategic move handling (based on implemented logic)
* Balanced gameplay experience

---

## ✨ Features

* Turn indicator for active player
* Win detection with result highlighting
* Draw state handling
* Instant reset / restart game
* Smooth move interactions
* Fully responsive layout (mobile + desktop)
* Clean and minimal animations
* Mode switching (Player vs Player / vs Computer)

---

## 🎨 UI/UX Philosophy

The interface is designed with a **minimal game-first approach**:

* No unnecessary visual clutter
* Focus remains entirely on gameplay
* Balanced spacing and alignment
* Subtle feedback animations (not distracting)
* Clear and readable game state
* Mobile-friendly touch interactions

The goal is to create a **focused, distraction-free casual gaming experience**.

## 🎮 How to Play

1. Select a game mode:

   * Player vs Player
   * Player vs Computer
2. Players take turns placing X and O
3. First to align 3 marks wins (row, column, or diagonal)
4. If no moves remain and no winner → draw
5. Click restart to play again
