# Tic Tac Toe

A modern, minimal tic tac toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- Clean centered board layout
- Score tracking for X, O, and draws
- Clear turn and win state display
- Instant restart and score reset controls
- Smooth cell feedback and winning-line highlight
- Mobile-friendly responsive layout
- Keyboard support for `1` through `9` and `R` to restart
- Play against another person or the built-in computer opponent

## How to play

Open `index.html` in a browser and take turns placing X and O on the board. The round ends automatically on a win or draw, and you can restart at any time with the control buttons.

Use the mode switch near the top to choose between local two-player mode and a computer opponent that plays as O.
